# Architecture compliance review — draft

Release ID / source commit / evidence bundle hash: supply at review.
Review scope: bare-metal single-tenant demonstrator. TOGAF ADM Phase G tailored review.
Decision: NOT REVIEWED. This is neither ATO nor PCI/FIPS certification.

For each requirement in requirements.csv, record implementation version, test result and immutable
evidence URI/hash. Review Business value, Application contracts, Data provenance/retention,
Technology support, Security trust boundaries and Operations recovery. Record baseline-to-target
gaps and validate ABB/SBB mapping. An open requirement cannot be reported as satisfied.

Exception record: ID, requirement, rationale, risk, compensating control, accountable owner,
expiry, remediation work item and approving authority. Reject unresolved ownership, fabricated
evidence, unknown artifacts or public exposure without explicit approval.

Sign-off fields: Architecture reviewer/date; Security reviewer/date; Operations reviewer/date;
Sponsor decision/date; release authority; separation-of-duties check; rollback authority.
All are unassigned until humans complete the review.
